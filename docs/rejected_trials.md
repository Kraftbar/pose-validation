# Rejected Trials Log

Institutional memory for `pure_c_plus` (and related) experiments: every
rejected trial with its numbers, per the rule in `AGENTS.md`. Do not retry
these without a materially new hypothesis. New rejected trials are appended
here; `README.md` keeps only the active blocker summary and current
conclusions.

Note (2026-06-11): the rejected opt-in flags and their code paths were removed
from `pure_c_plus` in an experiment-residue cleanup (see Design Direction in
`README.md`). The trial records below stay as the institutional memory; the
implementations are recoverable from git history at commit `8df5dc7` and
earlier.
